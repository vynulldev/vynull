# Bundled fonts

These woff2 files are the `latin` / `latin-ext` subsets of two royalty-free,
open-source fonts, served locally so the web UI needs no external font CDN.
Both are licensed under the **SIL Open Font License, Version 1.1** — the full
text is in [`OFL.txt`](OFL.txt) and at https://openfontlicense.org. The OFL
permits bundling, embedding, and redistribution with no fees or royalties.

|------|-------|-----------|
| **Geist Mono** | `geistmono-*.woff2` | Copyright 2024 The Geist Project Authors (https://github.com/vercel/geist-font) |
| **VT323** | `vt323-*.woff2` | Copyright 2011 The VT323 Project Authors (peter.hull@oikoi.com) |

The subset woff2 slices were obtained via the Google Fonts CSS API.
